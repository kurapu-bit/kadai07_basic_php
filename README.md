# ①課題名
- WE価値観調査「あなたはどっち派？」

## ②課題内容（どんな作品か）
- 二択（A/B）の価値観アンケートをWebアプリとして実装しました。Q1〜Q3の回答をフォームで送信すると、サーバ側でテキストファイルに回答履歴を保存し、結果ページで各設問のA/B比率を集計して円グラフ（Chart.js）で可視化します。

## ③アプリのデプロイURL
https://kyokara1031.sakura.ne.jp/kadai07/index.php

## ④アプリのログイン用IDまたはPassword（ある場合）
- 無し

## ⑤工夫した点・こだわった点
- 集計結果は「件数」と「割合（%）」を併記し、円グラフと合わせて数値が直感的に分かるようにしました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
- ファイルに蓄積したデータを読み取り、設問ごとにA/Bを集計してグラフに反映する流れ（PHP→JavaScriptへ値を渡し）の理解に時間がかかりました。（結果、質問項目をもっと増やしたかったのですが、時間の関係上一旦3問までとなってしまった）
